# 腾讯云服务器购买流程：从注册实名到开机连上的完整步骤，计费模式和配置项一次选对

腾讯云服务器购买流程本身不复杂：注册账号、完成实名认证、进购买页选计费模式和配置、确认订单支付，等 1–5 分钟服务器开通，拿到 IP 就能登录。麻烦的在中间那几步配置——地域、机型、镜像、带宽、安全组，每一项都会影响后面用起来顺不顺手，以及账单最后是多少钱。

> **选购速览**：个人项目、打算长期用，选「包年包月 + 按固定带宽」，配置按实际用途挑入门档；只做短期测试或一次性任务，用「按量计费」；能容忍中断的批处理任务可以看竞价实例。腾讯云没有一张固定价目表，价格跟地域、机型、带宽、购买时长绑定，购买页会实时算出费用。

## 购买前要准备什么

要准备三样：账号、实名认证、能付款的账户。

用手机号或邮箱在腾讯云官网注册账号。实名认证是购买中国大陆地域服务器的必要前提，个人和企业流程不同，提前做完能省掉下单时卡住的情况。账户里留够余额，或者绑定微信、网银等支付方式——官方支持的付款渠道包括余额支付、网银支付、微信支付、QQ 钱包支付。

顺带把需求想清楚：CPU 核数、内存、系统盘、带宽、操作系统。电商类应用优先考虑并发处理能力，内容分发类业务带宽要给足，这比“先买再说”省事。

## 腾讯云服务器有哪几种购买入口

腾讯云提供官网购买和 API 购买两条路。官网购买里又分活动机型、快速配置、自定义配置三个入口，差别在省事程度和灵活度。

**活动优惠机型**：配置固定，价格比同配置常规购买更优惠，适合不想在参数里打转的新手。新用户还能领专属优惠券或体验金，进一步压低首次成本。

**快速配置**：页面把常见场景的配置打包好，适合需求标准的用户，几分钟就能下单。

**自定义配置**：从地域到安全组逐项自己选，适合有特定要求的场景。下面以这个入口为主线展开。

**API 购买**：习惯用代码或自动化流程创建实例的，可以直接调「创建实例」接口，适合批量部署和集成进运维系统。

大多数个人用户和小团队，从活动机型或快速配置入手就够了，等业务跑起来再回头调配置。

## 自定义配置：每一项填什么

从「产品 > 计算 > 云服务器 > 立即选购」进入购买页，选自定义配置，按下面的顺序填。

**1. 地域与可用区**

选离用户最近的地域，访问延迟更低。买多台服务器时，建议分散到不同可用区，单点故障时不至于全军覆没。地域一旦选定，后续迁移要搬数据，买之前想清楚。

**2. 实例规格**

按用途选机型系列：通用型、计算型、内存型等，再定 CPU 和内存。实例规格页有各机型的详细参数，拿不准就从通用型起步。

**3. 镜像**

Windows Server 或 Linux（Ubuntu、CentOS、Debian 等）任选，也可以用自定义镜像或云镜像市场里的现成环境。生产环境建议选跟团队技术栈匹配的系统，减少后续折腾。

**4. 存储**

系统盘必选，默认 50GB，一般够用；数据盘可选，默认不添加，需要时再挂云硬盘，SSD 适合读写频繁的业务，HDD 适合冷数据。初期数据量不大，40–50GB 起步，后面可以在线扩容。

**5. 网络与带宽**

系统会给每个地域提供默认私有网络和子网，现有网络不满足要求可以自己建。需要外网访问就分配公网 IP。带宽计费有两种主流选择：按带宽计费是固定带宽、超出丢包，适合网络波动小的场景；按使用流量计费按实际流量收费，可以设峰值上限防止意外流量产生高额费用，适合波动大的场景。业务规模大、不同实例流量高峰错开的，可以看共享带宽包。

选带宽时留一点余量。固定带宽超了直接丢包，用户端表现就是访问卡顿，比多花几块钱难受得多。

**6. 登录方式与安全组**

登录方式三选一：自定义密码、关联 SSH 密钥（仅 Linux，更安全）、自动生成密码（通过站内信发送）。Linux 生产环境建议用密钥对。

安全组是实例的虚拟防火墙，要放行必要端口——网站业务通常开 80 和 443，远程管理开 22（Linux）或 3389（Windows）。没有现成安全组可以新建，也可以选已有安全组。

**7. 高级设置（可选）**

主机名、所属项目、CAM 角色、自定义数据都在这一层。自定义数据可以在实例启动时自动跑脚本，Linux 支持 Shell、Windows 支持 PowerShell，原始数据最大 16KB。批量部署时很有用。

此外还有几个默认可选项：安全加固默认免费开通 DDoS 防护和云镜主机防护；云监控和自动化助手同样默认免费开通。实例销毁保护默认不开启，开了之后控制台和 API 都无法销毁实例，防误操作。

## 几个容易踩的细节

**实例名称不是主机名。** 购买时填的实例名称只在控制台显示，限制 128 个字符以内，跟操作系统内部的 hostname 是两回事。hostname 要在高级设置里单独填。

**分配的独立公网 IP 不能和实例解绑。** 如果之后想把 IP 挪到别的实例上，需要先把它转成弹性公网 IP 再解绑。买之前想好 IP 的用途。

**竞价实例可能被回收。** 价格便宜，但市场供需变化时实例会被释放，适合容错性高的任务，别把不能中断的业务放上去。

**两种内设计费模式要走商务渠道。** 竞价实例（计划型）和包销计费目前都在内测，页面上开不了，需要联系商务经理开通。

**中国大陆地域对外提供网站服务要备案。** 自己用、跑内部服务，不涉及域名解析到网站，一般不受影响；一旦用域名对外提供网站服务，就要走 ICP 备案，提前预留时间。选海外地域节点则即买即用，无需备案。

## 买完之后：连接与初始化

Windows 实例用远程桌面连接，Linux 实例用 SSH。连不上先检查三件事：安全组有没有放行对应端口、密码或密钥是否正确、实例是否已经分配公网 IP。

连上之后按业务装环境——Web 服务器、数据库、运行程序。后续要调整配置，可以在控制台升配或降配，但地域变更需要迁移数据，不能直接改。

## 常见问题

**购买后多久能用上服务器？**
支付完成后立即开通，等待 1–5 分钟即可看到 IP 地址并登录管理。

**必须实名认证吗？**
购买中国大陆地域的服务器必须完成个人或企业实名认证，这是前提条件。

**买完还能改配置吗？**
可以，控制台支持升配和降配。地域不能直接改，需要迁移数据。

**短期项目选哪种计费？**
按量计费，按秒计费、小时结算，用完就释放，不用为闲置时间买单。

**新用户有什么优惠？**
可以领专属优惠券或体验金，活动机型的价格也比常规配置更优惠，具体以活动页展示为准。

## 最后：按你的情况对号入座

长期跑业务、流量稳定：包年包月 + 按固定带宽，把自动续费勾上，省心。

需求还没摸清、先试水：按量计费跑几天，看实际负载再转长期方案。

大数据计算、渲染这类能容忍中断的任务：竞价实例，价格一般是按量付费的 3%–20%。

下单前最后确认两件事：地域选得对不对（关系到延迟和备案），带宽留没留余量（关系到用户体验）。这两项后面改起来最麻烦。
